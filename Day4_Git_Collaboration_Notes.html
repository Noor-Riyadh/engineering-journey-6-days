Git Basics & Local Configuration

git config user.email "mohamed.mr@gmail.com"

git config --global user.name "Your Name"

📝 محاضرة Day 4

ربط الجهاز بالـ Remote Repo

git remote add origin https://github.com/username/repo.git
# 1. ربط الـ Local Repo بالـ Remote

git branch -M main
# 2. توحيد اسم البرانش الرئيسي لـ main

git push -u origin main
# 3. رفع الكود لأول مرة مع ربط الـ Tracking

📌 كلمة origin هي الاسم الافتراضي للـ Remote Repo بتاعك.

Git Clone مقابل Git Fork

📥 Git Clone

  • تنزيل نسخة طبق الأصل من المشروع على الجهاز
  • للاشتغال المباشر عليه

🍴 Git Fork

  • نسخة من مشروع حد تاني داخل حسابك على GitHub
  • للتعديل عليها بحرية وعمل Pull Request بعدين

📝 محاضرة Day 4 — Architecture Documentation

RFC & ADR

💬 RFC (Request For Comments)

  • مستند لاقتراح فكرة/حل ومناقشته مع الفريق
  • الفكرة والمشكلة + الحلول والبدائل
  • ليه اخترنا الحل ده بالذات
  • أسئلة مفتوحة للمناقشة
  • تسمية الملف: RFC-001-title.txt

🏛️ ADR (Architecture Decision Record)

  • سجل قرارات الهندسة المعمارية للمشروع
  • What: إيه القرار اللي اتاخد؟
  • Why: ليه اتاخد القرار ده؟
  • Trade-offs: إيه التنازلات المقبولة؟
  • Where: القرار مطبق فين في الكود؟
  • تسمية الملف: ADR-001.txt
